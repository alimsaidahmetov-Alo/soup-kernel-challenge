# Soup Kernel Challenge: Qwen2 Triton Optimization

Решение команды для хакатона **Soup Kernel Challenge** (Decentrathon 6.0), направленное на ускорение дообучения языковой модели `Qwen2.5-1.5B-Instruct` на бесплатном графическом процессоре Kaggle T4 с помощью кастомных ядер Triton без потери точности.

##  Что было сделано (Описание решения)
В процессе работы над проектом были разработаны и внедрены высокопроизводительные пользовательские ядра на базе **Triton**, заменяющие стандартные операции в архитектуре Qwen2:
1. **Кастомная SwiGLU активация (Forward & Backward):** Реализованы оптимизированные ядра `qwen2_mlp_act_fwd` и `qwen2_mlp_act_bwd` с настроенным размером блока (`BLOCK = 4096`) и количеством варпов (`num_warps = 8`), что позволило эффективно распараллелить вычисления на GPU и сократить накладные расходы.
2. **Оптимизированный FastRMSNorm (Forward & Backward):** Внедрены эффективные ядра нормализации (`qwen2_rmsnorm_fwd` и `qwen2_rmsnorm_bwd`), интегрированные через механизм патчинга `transformers.models.qwen2`.
3. **Сохранение точности:** Все изменения внедрены строго в рамках ограничений задачи — структура адаптера LoRA, гиперпараметры обучения и выходы модели остались полностью идентичны базовой версии.
